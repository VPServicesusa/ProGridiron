# Pro Gridiron — official site

The public website for **Pro Gridiron — Franchise** (iPhone & iPad). It hosts the
app's **support page**, **FAQ**, and **privacy policy** — the two URLs the App Store
requires — on a single page served by GitHub Pages.

**Live URL:** https://vpservicesusa.github.io/ProGridiron/

| File | Purpose |
|------|---------|
| `index.html` | The whole site (support, FAQ, privacy) in one file |
| `icon.png` | App icon, used as the hero image and favicon |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is (no Jekyll build) |

## App Store Connect URLs
- **Support URL:** `https://vpservicesusa.github.io/ProGridiron/#support`
- **Privacy Policy URL:** `https://vpservicesusa.github.io/ProGridiron/#privacy`
- **Marketing URL (optional):** `https://vpservicesusa.github.io/ProGridiron/`

## Updating
Edit `index.html` and push to `main`. GitHub Pages redeploys in a minute or two.

> ⚠️ **Before you ship ads or online modes:** the privacy policy currently states the
> app collects nothing and has no third-party services. That must change *before* such
> a build goes live. A ready-to-edit replacement block is in an HTML comment at the
> bottom of the privacy section in `index.html`. Update it, bump the "Last updated"
> date, and update the App Privacy answers in App Store Connect to match.
